# PlangOS v1 — stage 1 image

Plan source: `/shared/os/start.md` (reviewed with Ingi 2026-09-28). Branch `os/plangos`, off `os/v1-container`.

## Scope (this box, no Windows)

1. **PlangOS rootfs → WSL tarball** (`plangos/`)
   - Debian 13 (trixie) packages from `snapshot.debian.org`, pinned to a timestamp.
   - **Assembled, not installed.** apt resolves Chromium's dependency closure. Each `.deb` is unpacked with `dpkg-deb -x` into an empty root, and **no install scripts run**.
   - A deny-list keeps the following out: shells, coreutils, dpkg/apt, perl, systemd, the dbus daemon, login/passwd.
   - plang is published from `PLangHQ/plang@app-systems` (self-contained, linux-x64, invariant globalization, Playwright Node for linux-x64 only).
   - `/etc` is written by hand: `passwd`, `group`, an empty `fstab`, and the sealed `wsl.conf`. `/data` is kept for the `.db` files and the identity.
   - The tarball is deterministic: sorted entries, fixed owners, mtime = `SOURCE_DATE_EPOCH`.
2. **Manifest** (`manifest.json`): version, sha256, size. Signing is left open until PLang's signature format can be used by host plang.
3. **`start.ps1`**, copied from the `/shared/os` draft into the repo.
4. **Checks runnable here:**
   - 1.4: no setuid binaries, no shell, no way for `plang` to become root.
   - 1.5: two builds give the same sha256.
   - 1.6: compressed size ≤ 300 MB.
   - Spike: headless Chromium starts as a non-root user, with the sandbox on.

## Not here
- Checks 1.1–1.3, 1.7 and 1.8 need real Windows with WSL (Ingi's machine).
- Host plang's `start.goal`: the `terminal` and `container` modules and the Service channel are PLang-side work.

## Risks
- The Chromium dependency closure is large. The first test showed `/usr` at 766 MB **installed**, and it may not fit in 300 MB compressed.
- Skipping install scripts: caches (ld.so, fontconfig, gdk-pixbuf loaders, GSettings schemas) have to be generated by hand.
