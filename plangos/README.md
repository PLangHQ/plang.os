# PlangOS image

The Linux half of PlangOS: Debian 13 packages + self-contained plang + Chromium, sealed,
as a WSL rootfs tarball. Design and checks: `/shared/os/start.md`.

```
plangos/
├── build.sh          lock | image — the whole build
├── packages.conf     roots, deny-list, build helpers, snapshot date
├── packages.lock     220 packages, each pinned by sha256 (generated by `build.sh lock`)
├── mktar.py          deterministic tarball; refuses setuid/setgid files
├── checks.py         checks 1.4 + 1.6 + "every ELF finds its libraries"
├── run-local.sh      run a command inside a built rootfs as uid 10001 (Linux, no root)
├── rootfs/etc/       the only hand-written files: wsl.conf, passwd, group, nsswitch.conf
├── keys/             Debian archive keyring (sha256 pinned in build.sh)
├── host/start.ps1    Windows launcher draft (gets host plang, runs start.goal)
└── dev/import.ps1    dev only: wsl --import a built image without host plang
```

## Build (Linux or WSL, no root)

```sh
# 1. plang, from PLangHQ/plang (branch app-systems)
dotnet publish PlangConsole/PLangConsole.csproj -c Release -r linux-x64 --self-contained true \
  -p:InvariantGlobalization=true -p:PlaywrightPlatform=linux-x64 \
  -p:Deterministic=true -p:ContinuousIntegrationBuild=true -o /tmp/plang-publish
cp -r os /tmp/plang-publish/os          # the runtime's system goals

# 2. the image
plangos/build.sh image /tmp/plang-publish         # -> plangos/out/plangos-amd64.tar.xz + manifest
python3 plangos/checks.py plangos/.work/rootfs plangos/out/plangos-amd64.tar.xz

# 3. try it
plangos/run-local.sh plangos/.work/rootfs /opt/plang/plang
```

`build.sh lock` re-resolves `packages.conf` against the snapshot date. Run it only when
changing packages or moving the snapshot; commit the new `packages.lock`.

Needs: bash, dpkg-deb, curl, python3, xz, objdump, util-linux `unshare` ≥ 2.36 with
unprivileged user namespaces; apt-get for `lock` only.

## How the rootfs is made

No container runtime, no root, **no maintainer scripts**. apt resolves the closure from an
empty system, and each non-denied `.deb` is unpacked with `dpkg-deb -x`. The caches that
install scripts normally make (ld.so.cache, fonts, GSettings schemas, the CA bundle) are
generated by helper packages run in an unprivileged chroot; the helpers are then removed.
So every file in the image comes from a locked `.deb`, from plang, or from `rootfs/`.

## Layout in the image

| Path | Owner | What |
|---|---|---|
| `/opt/plang` | root | plang runtime + `os/` system goals; `os-packages.txt` lists every unpacked package |
| `/home/plang` | plang (10001) | the user's apps and data (`.db`) — the only writable tree besides `/tmp` |
| `/usr/lib/chromium/chromium` | root | the browser, started directly by plang (Debian's launcher script is removed: no shell) |
| `/etc/wsl.conf` | root | interop off, automount off, default user `plang`, no boot command |

## On Windows (until host plang exists)

```powershell
.\plangos\dev\import.ps1 -Dir <folder with plangos-amd64.tar.xz and manifest-amd64.json>
wsl -d PlangOS
```
